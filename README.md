# 🔦 Spotlight Effect

## 📌 About The Project

The **Spotlight Effect** is a simple and interactive JavaScript DOM project that creates a spotlight effect on a webpage. It uses mouse movement to create a dynamic lighting effect, highlighting a specific area of the screen while keeping the remaining background dark.

This project is built using HTML, CSS, and JavaScript. It helps beginners understand DOM manipulation, mouse events, and dynamic styling using JavaScript.

## ✨ Features

- 🔦 Dynamic Spotlight Effect
- 🖱️ Follows Mouse Cursor Movement
- 🎨 Smooth Lighting Effect
- ⚡ Real-Time Interaction
- 📱 Simple and Clean UI
- 💻 Beginner-Friendly JavaScript Project

## 🛠️ Technologies Used

- **HTML5** – For webpage structure.
- **CSS3** – For styling and visual effects.
- **JavaScript** – For DOM manipulation and mouse movement functionality.

## 🧠 JavaScript Concepts Used

- DOM Manipulation
- `querySelector()`
- `addEventListener()`
- `mousemove` Event
- `event.clientX`
- `event.clientY`
- Dynamic CSS Styling

## 🚀 How To Run This Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Himanshu123-hub/spotlight-effect.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Move your mouse around the webpage to experience the spotlight effect.

## 🎯 Learning Objective

The main objective of this project is to improve JavaScript DOM manipulation skills by creating an interactive spotlight effect using mouse events and dynamic CSS properties.
